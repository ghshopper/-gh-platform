# GH Shopper — تطبيق إدارة البزنس (iPhone)

تطبيق Flutter لإدارة الطلبات والعملاء وفواتير البيع والشراء والدفعات.

## المزايا
- **الطلبات**: أكثر من قطعة في الطلب، حالة لكل قطعة (بانتظار الشراء → تم الشراء → وصلت مسقط → تم التسليم)، رسوم توصيل منفصلة.
- **الدفعات**: عربون ودفعات متعددة، والمتبقي يُحسب تلقائياً.
- **فاتورة PDF** بالعربي والإنجليزي بهوية GH، تُشارك مباشرة (واتساب، ملفات، طباعة).
- **رسائل واتساب جاهزة**: تأكيد الطلب، تم الشراء، وصل الطلب، تذكير بالمتبقي، تم التسليم — تقدر تعدّلها قبل الإرسال.
- **فواتير الشراء**: المحل، العملة وسعر الصرف، وربط كل قطعة بتكلفتها لمعرفة الربح.
- **الملخص**: المبيعات، المحصّل، الربح، والشغل الحالي.

## البنية
- `lib/` كود التطبيق، `supabase/migrations/` جداول قاعدة البيانات (`gh_*` داخل مشروع Supabase «mspa»).
- كل الجداول محمية بـ RLS: كل مستخدم يشوف بياناته فقط.

## البناء والرفع على TestFlight
كل دفع (push) على `main` يشغّل `.github/workflows/ios.yml`:
1. فحص الكود والاختبارات على Linux.
2. على macOS: توليد مشروع iOS، البناء، التوقيع عبر fastlane match، والرفع على TestFlight.

### الأسرار المطلوبة (Settings → Secrets and variables → Actions)
| الاسم | القيمة |
|---|---|
| `ASC_KEY_ID` | Key ID لمفتاح App Store Connect API |
| `ASC_ISSUER_ID` | Issuer ID |
| `ASC_KEY_P8` | محتوى ملف ‎.p8 كامل |
| `APPLE_TEAM_ID` | Team ID من حساب المطورين |
| `MATCH_PASSWORD` | كلمة سر تختارها لتشفير ملفات التوقيع |

ومتغيّر (Variables) اسمه `BUNDLE_ID` إذا كان غير `app.ghshopper.com`.
